# Number-Game
An interactive Guess the Number game built with Streamlit, featuring real-time data tracking with Pandas and beautiful visualizations with Matplotlib. Test your intuition while the app tracks your performance and provides detailed analytics
**Features**
🎮 Gameplay
Multiple Difficulty Levels: Easy (1-50), Medium (1-100), Hard (1-200), Expert (1-500)
Smart Hint System: 4 progressive hints to help you narrow down the number
Real-time Range Tracking: Watch your valid number range shrink with each guess
Player Profiles: Enter your name to track personal statistics
Timer: Track how fast you can find the number
📊 **Data Analytics**
Game History: Complete record of all games played with timestamps
Performance Metrics: Average attempts, best scores, and personal records
Leaderboard: Compete with yourself or others for the best score
Player Statistics: Individual performance tracking per player
📈 VisualizationLive Guessing Progress:
See your guesses approach the target number
Distance Chart: Visualize how close each guess was to the target
Performance Trends: Track your improvement over time
Distribution Analysis: Understand your guessing patterns
**How to Play**
Enter your name in the sidebar to track personal statistics
Select difficulty level (changes the number range)
Start guessing numbers in the main input field
Use hints if you get stuck (up to 4 hints available)
Track your progress in real-time with the visualizations
View your history and performance in the analytics tabs
Start a new game anytime using the sidebar button
